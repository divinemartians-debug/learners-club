# 📚 Learners Club

Learn new skills. Build your future.

Learners Club is an online learning platform designed to help beginners learn digital skills through simple written lessons.

## 🎓 Courses

- Artificial Intelligence (AI)
- HTML and CSS
- JavaScript and Programming
- AI Content Creation

## ✨ Features

- Browse available courses
- View course prices
- Beginner-friendly learning
- Mobile-friendly website
- Planned bank transfer payments
- Planned student accounts and lesson access

## 🛠️ Built With

- HTML
- CSS
- JavaScript

To make learning digital skills accessible and affordable.
